# assets

Drop your photos here, then swap the matching `placehold.co` URL in [`../README.md`](../README.md)
for `assets/<file>`. Shots to take:

| File | What to shoot |
|------|---------------|
| `hero.png` / `hero.gif` | Badge in-hand with the LED ring lit + a few 1-bit prints fanned beside it (a "develops-in" gif is even better). |
| `leds.gif` / `leds.png` | The LED ring mid-show — the racing dot / rainbow chase. |
| `boot-mode.png` | The `BAOCHIP` drive mounted on your desktop with the badge plugged in (proof it's in boot mode). |
| `samples.png` | A grid of a few 1-bit photos the badge actually took (screenshot the gallery wall, or the raw PNGs). |
